# PRCP-1017 Automobile Price Prediction

Final year internship / capstone project on predicting car prices using machine learning.

**Student:** Gopala Krishna Avula  
**Project Code:** PRCP-1017-AutoPricePred

## About the Project

This project uses the 1985 Auto Imports dataset to:

1. Analyse car features and price patterns (EDA)
2. Build regression models to predict car price
3. Compare models and suggest the best one
4. Document challenges faced during the work

All main work is done in a **single Jupyter notebook**, as required for submission.

## Dataset Files

| File | Description |
|------|-------------|
| `auto_imports.csv` | Car specification data (no header row, `?` = missing) |
| `auto_imports_names.txt` | Attribute / column information |
| `PRCP-1017-AutoPricePred (4).docx` | Project requirement document |

## How to Run

```bash
# install libraries
pip install -r requirements.txt

# open the notebook
jupyter notebook PRCP-1017_AutoPricePred_Internship_Project.ipynb
```

Then run all cells from top to bottom.

## Project Notebook

`PRCP-1017_AutoPricePred_Internship_Project.ipynb` contains:

- Data loading and cleaning
- Exploratory Data Analysis (Data Analysis Report)
- Multiple ML models for price prediction
- Model Comparison Report
- Challenges Faced Report
- Conclusion and recommendation

## Models Used

- Linear Regression
- Ridge / Lasso Regression
- Decision Tree
- Random Forest
- Gradient Boosting
- KNN Regressor
- SVR
